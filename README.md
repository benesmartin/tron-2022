# TRON (WinForms, 2022)

Jednoduchá hra jako projekt ze střední - dvě "motorky" kreslí stopu a snaží se nenarazit.  
Archivuji jako vzpomínku na začátky s C# a WinForms 😄

## Demo

![Demo gif](https://media.martinben.es/trondemo.gif)

## Funkce

- 2 hráči na jedné klávesnici (WASD vs šipky)
- **mezerník** = start/pauza
- stopa jako překážka (kolize = konec kola)
- skóre na 3 kola, jednoduché message boxy

## Technologie

- C# WinForms (.NET 5+)

## Jak spustit

- Otevři ve **Visual Studio 2022**
- Spusť `FormTron`
